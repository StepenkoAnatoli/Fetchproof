# Project workflow preview

[`research-overview.svg`](research-overview.svg) is the editable source used at
the top of the project README. [`fetchproof-workflow.png`](fetchproof-workflow.png)
is the same illustration exported at 1440 × 820 for community posts and services
that require a raster image. It illustrates the workflow; it is not a screenshot
of a product interface.

The preview follows the project from framing questions through collection,
source review, and the configured checks, then to an authored brief for the
builder. Its footer keeps source review distinct from a passing check.

Suggested alt text: “Fetchproof workflow: frame questions, collect primary
sources, review evidence, run checks, and hand an authored brief to the builder.”

When sharing the image, link to the [repository](https://github.com/StepenkoAnatoli/Fetchproof)
so readers can find the setup guide, source, contribution instructions, and
[license](../../LICENSE).
